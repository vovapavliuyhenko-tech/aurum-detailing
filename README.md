# AURUM Detailing — сайт детейлинг-центра (Краснодар)

Вёрстка по макету из Figma: десктоп 1440 и адаптив под телефон.

- `index.html`, `styles.css`, `script.js` — страница, анимации и функциональность (калькулятор стоимости, формы с маской телефона, сравнение «до/после», FAQ, меню)
- `common.js` — баннер cookie
- `privacy.html` — политика конфиденциальности (реквизиты уточнить)
- `img/` — изображения из макета (WebP)

## Локальный запуск

```bash
node server.js
```

Сайт откроется на http://localhost:5509.
